# Submissions

Each lab has a matching submission folder. Treat these folders as your lab notebook and hand-in area.

Recommended workflow:

```powershell
python tools/course.py show lab00
python tools/course.py grade lab00
python tools/course.py handin lab00
```

Rules:

- Replace every `TODO` before grading.
- Put the number of hours spent in `time.txt`.
- Do not put large datasets or model weights here.
- Keep evidence concise: commands, screenshots paths, metrics, and short analysis.
