# Lab 08: Final Project - A Reproducible YOLO System

## Goal

Deliver a compact, reproducible YOLO project with a clear problem, dataset, model, evaluation, demo, and next-step plan.

## Background

The final project is not judged by raw mAP alone. A good beginner project is honest, reproducible, and specific. It should make clear what the model can do today and what evidence would be needed before real use.

## Tasks

1. Define the problem and target user.
2. Document dataset size, sources, classes, and split.
3. Document training commands and cloud environment.
4. Summarize metrics and error analysis.
5. Include at least five prediction examples or paths to them.
6. Explain deployment choice.
7. Fill in `submissions/lab08/final_project.md`.
8. Record time spent in `submissions/lab08/time.txt`.

## Hints

- A small honest project beats a vague big one.
- Include failure cases, not just successful detections.
- Your "Next" section should be actionable: collect X, relabel Y, test Z.
