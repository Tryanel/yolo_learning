# YOLO 8 周学习地图

这份路线面向零模型经验学习者。你不需要先学完整深度学习数学，也不需要从论文开始。每周的目标都是可验证的：能跑出结果、能解释结果、能改进结果。

## 总目标

完成一个自己的目标检测项目，例如：

- 检测桌面上的手机、杯子、鼠标、键盘
- 检测安全帽或反光衣
- 检测水果种类
- 检测停车位车辆
- 检测某类工业零件缺陷

## 8 周路线

| 周次 | 主题 | 最终产物 |
| --- | --- | --- |
| 1 | 环境与 Python 最小基础 | 环境检查通过，能运行脚本 |
| 2 | 目标检测概念 | 能解释框、类别、置信度、IoU、mAP |
| 3 | 预训练模型预测 | 能检测图片/视频并保存结果 |
| 4 | 数据集与标注 | 得到一个 YOLO 格式小数据集 |
| 5 | 训练自定义模型 | 训练出自己的 `best.pt` |
| 6 | 评估与改进 | 完成错误案例分析和一次改进 |
| 7 | 部署与 demo | 跑通导出或实时检测 demo |
| 8 | 最终项目 | 完成 README、示例图、脚本和复盘 |

## 学习原则

1. 先运行，再解释。
2. 数据质量通常比调参更重要。
3. 每次只改一个变量，方便判断效果。
4. 记录失败案例，它们比成功截图更值钱。
5. 不急着追求高分，先让流程完整闭环。
