# Week 08 - 最终项目

## 本周目标

整理一个能展示、能复现、能讲清楚的 YOLO 小项目。

## 最终项目要求

你的项目至少包含：

- 清晰的问题定义：检测什么，为什么检测。
- 数据集说明：来源、类别、数量、划分方式。
- 训练配置：模型、epochs、imgsz、batch。
- 评估结果：mAP、错误案例、改进记录。
- Demo：图片、视频或摄像头推理。
- 复盘：哪里做得好，下一步怎么改。

## 推荐 README 结构

```text
# 项目名称

## 目标
## 数据集
## 训练方法
## 结果
## 错误案例
## 如何运行
## 下一步
```

## 检查点

你能用 3 分钟讲清楚：

- 你的模型解决什么问题？
- 数据集有什么局限？
- 模型目前最常犯什么错？
- 如果再给你一周，你会优先改什么？
