# Week 01 Assignment - 环境体检

## 作业目标

证明你已经有一个能跑 YOLO 学习脚本的环境。

## 任务

1. 安装依赖。
2. 运行：

```powershell
python scripts/check_environment.py
```

3. 把输出复制或截图保存到 `notes/week_01.md`。
4. 回答下面 3 个问题：

- 你的 Python 版本是多少？
- PyTorch 是否检测到 GPU？
- 如果没有 GPU，你准备用本地 CPU 还是 Colab 训练？

## 通过标准

- 环境脚本运行完成。
- 你知道当前环境是否适合训练。
- 你能解释虚拟环境的作用。
